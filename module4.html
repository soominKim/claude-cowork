나의 Skill 만들기

업무 종류와 상관없이, 내가 반복하는 워크플로우 하나를 골라 나만의 스킬로 만듭니다.

4.1

반복 워크플로우 고르기

스킬로 만들 반복 업무 하나와, 그 일에 필요한 자료 묶음을 정합니다.

이번 실습에서는 내가 자주 반복하는 업무를 하나의 Skill로 만듭니다. 업무 종류는 상관없습니다. 수업 전에 생각해 온 작업이 있다면 그대로 사용하고, 아직 없다면 “내가 반복적으로 수행하고 있고, 가능하면 자동화하고 싶은 작업”을 하나 고릅니다.

좋은 주제는 한 번 하고 끝나는 작업보다, 비슷한 순서로 여러 번 반복되며 몇 개의 단계로 나눌 수 있는 작업입니다.

이런 작업이 좋은 주제입니다 (예시 11개)
  • 강의 자료나 여러 콘텐츠를 모아 핵심 내용을 요약하고 강의 노트로 정리하기
  • 매주 특정 분야의 뉴스나 콘텐츠를 찾아 카드뉴스 초안 만들기
  • 매주 전달받는 리포트에서 필요한 숫자와 내용을 뽑아 정해진 형식으로 주간 보고서 작성하기
  • 회의가 끝날 때마다 회의록을 읽고 결정사항 / 담당자 / 다음 액션 정리하기
  • 논문이나 보고서를 읽고 연구 목적 / 방법 / 결과 / 시사점 형식으로 정리하기
  • 고객 인터뷰 기록을 모아 주요 니즈와 반복되는 문제점 분류하기
  • 여러 지원자 자료를 동일한 기준으로 읽고 평가표 초안 작성하기
  • 매번 새로운 프로젝트를 시작할 때 자료를 받아 PRD 또는 프로젝트 브리프 만들기
  • 특정 웹사이트들을 확인해 정보를 모은 뒤 시장·경쟁사 업데이트 작성하기
  • 매주 SNS 콘텐츠 후보를 모아 게시물 아이디어 → 초안 → 제목/해시태그까지 생성하기
  • 행사나 수업이 끝난 뒤 설문 데이터를 받아 주요 결과와 개선사항 정리하기

이런 워크플로우가 좋습니다

가능하면 아래 조건을 만족하는 작업을 골라 봅니다.

①반복된다매주, 매달 또는 프로젝트마다 비슷하게 수행하는 작업
②순서가 있다예: 자료 수집 → 분류 → 요약 → 결과물 작성
③단계별로 나눌 수 있다각 단계를 하나의 작은 작업처럼 설명할 수 있는 업무
④입력과 결과물이 비교적 명확하다무엇을 받아서(Input) 무엇을 만드는지(Output) 설명할 수 있는 업무

함께 준비할 것: 나의 작업에 필요한 ‘데이터 묶음’

Skill은 단순히 프롬프트만 만드는 것이 아니라, 내가 실제로 일할 때 참고하는 자료와 규칙을 함께 제공할수록 훨씬 유용해집니다. 선택한 워크플로우를 수행할 때 평소 사용하는 자료 몇 가지를 함께 준비합니다.

  • 내가 정리해야 하는 원본 데이터 / CSV / Excel
  • 매주 받는 보고서나 PDF
  • 내가 자주 참고하는 웹사이트 또는 URL 목록
  • 과거에 작성했던 좋은 결과물 예시
  • 회의록을 정리할 때 사용하는 회의록 템플릿
  • 보고서나 제안서의 작성 양식
  • 자주 사용하는 분류 기준이나 체크리스트
  • 콘텐츠 제작에 사용하는 브랜드 가이드 / 문체 예시
  • 분석할 인터뷰 기록이나 문서 샘플
Input + Output을 함께

가능하다면 원본 자료(Input) + 원하는 결과물의 예시(Output)를 같이 준비하면 가장 좋습니다. 실제 고객정보·미공개 수치·인사 자료는 넣지 말고, 공개 자료나 이름·숫자를 바꾼 샘플을 사용합니다.

이것만 정리하면 준비 끝

  1. 내가 자동화하고 싶은 반복 업무는 무엇인가?예: 매주 AI 뉴스를 모아서 수업용 카드뉴스 초안을 만든다.
  2. 지금은 어떤 순서로 이 일을 하고 있는가?예: 뉴스 검색 → 기사 선택 → 핵심 내용 요약 → 5장 구성 → 제목 작성
  3. 이 작업에 필요한 자료는 무엇인가?예: 뉴스 사이트 5개, 이전 카드뉴스 3개, 카드뉴스 작성 템플릿
  4. 최종적으로 어떤 결과물이 나오면 좋은가?예: 제목 + 5장의 카드뉴스 구성안 + 각 장의 문구

완벽하게 자동화할 수 있는 일을 찾을 필요는 없습니다. “이 일을 할 때마다 비슷한 과정을 또 하고 있네?”라고 느끼는 작업 하나면 충분합니다.

4.2

나의 Skill 만들기

고른 워크플로우를 설계안 → 초안 → 시험 실행 → 수정 → 저장 순서로 스킬로 만듭니다. 업무 종류와 상관없이 같은 순서로 진행합니다.
먼저 · 내 스킬 영문 이름 정하기

아래에 스킬 이름을 입력하면 이 장의 폴더 이름과 모든 프롬프트가 그 이름으로 바뀝니다. 복사 버튼을 누르면 바뀐 이름 그대로 복사됩니다.

영문 소문자 · 숫자 · 하이픈만 씁니다(띄어쓰기는 하이픈으로 바뀝니다). 2~4단어로, 이름만 보고 무슨 일을 하는지 알 수 있게 짓습니다.

예시 (누르면 입력됩니다)
STEP 1새 프로젝트와 자료 폴더 준비

프로젝트 → 새 프로젝트에서 이름을 나의 스킬로 정합니다. 바탕화면 등에 weekly-ai-cardnews 폴더를 만들고, 그 안에 input 폴더를 하나 만듭니다. 준비한 자료는 나누지 말고 전부 input/에 넣습니다. 그다음 폴더 사용으로 weekly-ai-cardnews 폴더를 연결합니다.

weekly-ai-cardnews/
weekly-ai-cardnews/
  input/    준비한 자료를 모두 넣는 곳 (원본 · 예시 · 양식 · 참고 URL 메모 등)
  skill/    스킬 초안 (STEP 3에서 Claude가 만듭니다)
  output/   실행 결과 (STEP 4부터 Claude가 만듭니다)

자료가 적어도 괜찮습니다. 원본 자료 1~2개와 좋은 결과물 예시 1개만 있어도 시작할 수 있습니다. 자주 보는 웹사이트는 참고사이트.txt에 한 줄에 하나씩 적어 같이 넣습니다. 파일 종류는 Claude가 STEP 2에서 스스로 분류합니다.

선택 · 자료를 미리 나눠 넣고 싶다면

자료가 많거나 역할이 섞여 헷갈린다면 input/ 대신 아래처럼 나눠 넣어도 됩니다. 이때는 STEP 2 프롬프트의 [자료 위치]에 폴더별 역할을 함께 적습니다.

weekly-ai-cardnews/
weekly-ai-cardnews/
  input/      원본 자료 (CSV · Excel · PDF · 회의록 등)
  examples/   과거에 만든 좋은 결과물 예시
  rules/      양식 · 템플릿 · 체크리스트 · 브랜드 가이드 · 문체 예시
  urls.txt    자주 참고하는 웹사이트 (한 줄에 하나, 필요할 때만)
STEP 2워크플로우를 설명하고 설계안 받기

4.1에서 정리한 네 가지를 [ ] 자리에 채워 보냅니다. 스킬 이름은 위에서 정한 이름이 자동으로 들어갑니다.

1 · 워크플로우 설명하고 설계안 받기
내가 반복하는 업무를 "weekly-ai-cardnews" 스킬로 만들고 싶어. 아래 내용을 바탕으로 스킬 설계안을 먼저 만들어줘.
아직 스킬을 만들거나 저장하지 마.

[내 업무]
1. 자동화하고 싶은 반복 업무: [예: 매주 AI 뉴스를 모아 수업용 카드뉴스 초안 만들기]
2. 지금 하는 순서: [예: 뉴스 검색 → 기사 선택 → 핵심 요약 → 5장 구성 → 제목 작성]
3. 필요한 자료: [예: 뉴스 사이트 5개, 이전 카드뉴스 3개, 카드뉴스 작성 템플릿]
4. 원하는 결과물: [예: 제목 + 5장의 카드뉴스 구성안 + 각 장의 문구]

[자료 위치]
연결한 폴더의 input/ 안에 있는 파일을 모두 읽어. 자료는 나누지 않고 한곳에 넣었어.
먼저 파일마다 아래 중 무엇인지 표로 분류해서 보여줘. 애매한 파일은 나에게 물어봐.
- 원본 자료: 매번 새로 들어오는 재료
- 좋은 결과물 예시: 이렇게 만들고 싶은 완성본
- 양식 · 규칙: 템플릿, 체크리스트, 브랜드 가이드, 문체 예시
- 참고 사이트: 자주 보는 웹사이트 목록

[설계안에 담을 것]
1. 스킬 이름: weekly-ai-cardnews (더 나은 이름이 있으면 1개만 제안) + 한 줄 설명
2. 이 스킬을 언제 쓰는지 (발동 조건)
3. 입력(Input)과 결과물(Output)의 형식
4. 단계별 작업 순서와 각 단계에서 지킬 규칙
5. 스킬에 함께 넣을 파일 (양식 · 예시 · 체크리스트)
6. 사람이 꼭 확인해야 할 부분

설계안을 보여준 뒤, 빠졌거나 애매한 부분을 3개 이내로 나에게 질문해줘.

확인: ① 자료 분류표가 맞는지 보고 틀린 것은 바로잡습니다. ② 설계안의 단계가 내가 실제로 일하는 순서와 같은지 봅니다. ③ Claude의 질문에 짧게라도 답합니다. 답이 구체적일수록 스킬이 정확해집니다.

2 · 스킬 초안 만들기 (저장하지 않기)
답변을 반영해서 설계안대로 "weekly-ai-cardnews" 스킬 초안을 만들어줘.

- input/의 양식 · 예시 중 필요한 파일은 skill/ 안에 복사해 넣고, 본문에서 언제 참고하는지 적어.

아직 저장하지 않습니다

STEP 3~5는 초안을 만들고 시험하는 단계입니다. 결과를 확인하고 고친 뒤 STEP 6에서 한 번만 저장합니다. 중간에 Claude가 저장할지 물으면 “아직 저장하지 마”라고 답합니다.

STEP 4초안대로 실행하고 결과 확인하기
3 · 초안대로 실행하기
skill/SKILL.md를 처음부터 읽고, 적힌 순서 그대로 따라서 input/ 자료로 실제로 한 번 실행해줘.
아직 스킬로 저장하지 마.

- 결과물은 output/에 새 파일로 저장해. input/의 원본은 고치지 마.
- 실행하면서 SKILL.md의 몇 번째 단계를 하고 있는지 단계마다 한 줄로 알려줘.
- SKILL.md에 적혀 있지 않아서 네가 임의로 판단한 부분이 있으면 따로 모아서 알려줘.
- 좋은 결과물 예시가 있으면 이번 결과와 비교해서 부족한 점을 표로 정리해줘.

확인: output/의 결과 파일을 직접 열어 아래를 봅니다.

형식 · 분량내가 원한 결과물 형식과 분량에 맞는다.
