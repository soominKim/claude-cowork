6.1

Key Takeaways

오늘 실습한 다섯 모듈의 핵심만 모았습니다.
오늘의 한 문장

반복하는 업무 규칙은 스킬로 남기고, 필요한 도구는 MCP로 연결하면, Cowork가 내 방식대로 일합니다.

1Cowork 기능 살펴보기
  • 폴더를 연결하면 Claude가 내 파일을 직접 읽고, 결과는 output/에 새 파일로 남깁니다.
  • 엑셀·HTML·아티팩트처럼 바로 쓰는 결과물을 만들고, 아티팩트는 계정에 저장해 다시 엽니다.
  • 프로젝트와 지침에 배경·규칙을 저장하면 매번 다시 설명하지 않아도 됩니다.
  • 승인 모드로 실행 전에 어디까지 확인할지 정합니다.

2스킬 다루기
  • 스킬은 반복 업무의 순서·형식·규칙을 담은 지침서(SKILL.md)입니다.
  • 공개 스킬은 프롬프트 한 줄로 저장하고 /이름으로 바로 씁니다.
  • 공개 스킬을 고치면 우리 팀 규격(team-share)이 되고, CI 같은 자산을 묶으면 결과가 일정해집니다.

3업무 실습
  • 만든 스킬을 이어 붙여 워크샵 내용을 팀 공유자료(PPT·공유문)까지 한 흐름으로 만듭니다.
  • 결과물은 공유 전에 사실·수치·브랜드 규격을 사람이 확인합니다.
다시 보기 →
4나의 Skill 만들기
  • 반복되고, 순서가 있고, 단계로 나뉘고, 입력과 결과가 분명한 업무가 좋은 주제입니다.
  • 원본 자료(Input)와 좋은 결과물 예시(Output)를 함께 주면 스킬의 품질이 올라갑니다.
  • 설계안 → 시험 실행 → 수정 → 저장, 이 고리를 돌며 다듬습니다.
다시 보기 →
5MCP로 외부 도구 연결하기
  • MCP는 AI용 USB-C입니다. Cowork에서는 커넥터로 연결합니다.
  • 스킬은 일하는 방법, MCP는 손이 닿는 도구입니다. 둘을 함께 쓸 때 가장 강력합니다.
  • 믿을 수 있는 서버만 연결하고, 권한과 비용(크레딧)을 먼저 확인합니다.
