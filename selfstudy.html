- 제휴사 표기가 흔들림(제휴사A / 제휴사 A / 제휴사a) → 같은 회사로 판단되면 하나로 통합
- 구분 표기도 통일(리워드지급 / 리워드 지급 → 하나로)
- 금액의 쉼표·앞뒤 공백 제거, 통화 표기 "원"과 "KRW"는 KRW로 통일
- USD 건은 원화로 환산하지 말고 별도 표시. 환율 정보가 없으므로 "확인 필요"로 표시
- 날짜·제휴사·구분·금액이 같은 행이 있으면 하나로 합치고, "중복 의심"이라고 비고에 남겨줘
  (비고 칸만 다른 것도 중복으로 봐. 임의로 삭제하지 말고 원본 행 수도 같이 적어줘)
- 금액이 빈 칸이면 0으로 채우지 말고 "확인 필요"로 표시

  건수가 다른 월은 비교 대상이 아니라고 표 아래에 적어줘

## 번역 규칙

1. 표에 있는 용어는 표의 표기를 그대로 쓴다. 문맥이 달라 보여도 바꾸지 않는다.
2. **`shall`(의무) / `may`(재량)를 구분한다.** 의무를 재량으로 바꾸면 계약 리스크가 된다.
3. 조항 번호(3.1, B.2)·별지 명칭·표 구조를 유지한다. 숫자는 바꾸지 않고, 환산할 때는 **원문 숫자를 괄호로 병기**한다. 예: 12억 달러(USD 1.2 billion)
4. **원문의 오류·모순을 고치지 않는다.** 그대로 옮기고 `[확인 필요]`로 표시한다. 없는 내용을 추가하거나 문장을 다듬지 않는다.
5. 용어집에 없는 용어는 **한국어 + 원어 병기** 후 끝에 "용어집 추가 후보"로 모은다. 문서 성격(대외비 / 비구속 / 감사 전 추정치)은 번역문에도 남긴다.

2. shall / may / shall not 을 구분해서 옮겨:
   shall = "~하여야 한다"(의무) / may = "~할 수 있다"(재량) / shall not = "~하여서는 안 된다"
   단 의무 주체가 없는 "선언적 shall"은 "~한다 / ~로 한다"로 옮겨.
   (Neither party shall be liable → "책임을 지지 아니한다" / shall be governed by → "준거법은 ~법으로 한다")
   "아니하여야 한다"처럼 어색한 문장이 되면 선언적 shall이니 다시 봐.

   (예: USD 1.2 billion → 12억 달러(USD 1.2 billion) / 327bps → 327bp)
5. 원문의 오류나 모순을 고치지 마. 그대로 옮기고 그 자리에 [확인 필요] 표시를 남겨.
6. 원문에 없는 내용을 추가하거나 문장을 부드럽게 다듬지 마.

## 단계 표기 규칙 (반드시 이 4단계로만 표기)
- `논의` : 당국·업계 논의만 있고 문서화된 안이 없음
- `초안` : 안이 공개됐고 의견수렴 중 (입법예고 · 가이드라인 초안 포함)
- `확정` : 최종 문안이 확정됨 (단, 시행일은 별도)
- `시행` : 실제로 효력이 발생함

## 1. 국내 · 스테이블코인 발행·유통 규율
- 현재 단계: **초안** (9월 2일 입법예고 시작, 의견수렴 40일)
- 남은 절차: 의견수렴 → 규제개혁 심사 → 국회 통과 → 시행령 → 시행
- 시행일: **미정**
- 주요 내용(초안 기준): 발행자 자기자본 요건, 준비자산 100% 예치 및 월별 외부검증,
  발행·소각 내역 공시, 유통 플랫폼의 이용자 고지 의무
- 우리 사업 영향(가정): 원화 스테이블코인 취급 시 준비자산 검증 리포트 수취 절차가 필요할 수 있음
- 확인 필요: 기존 이용자보호 규정과의 중복 적용 여부

## 2. 국내 · 법인 실명계좌 허용 범위 확대
- 현재 단계: **논의**
- 문서화된 안 없음. 당국 간담회에서 "단계적 확대 필요성"이 언급된 수준
- 시행일: 해당 없음
- 우리 사업 영향(가정): 법인 고객 온보딩 프로세스 사전 설계 검토 정도

## 3. 국내 · 커스터디(수탁) 사업자 등록제

## 4. 유럽권 · 감독기구 토큰 분류 가이드라인

[언제 쓰는가] 클리핑·지표 파일을 주면서 "주간 브리핑 만들어줘"라고 할 때

[항상 이 순서로]
1) 보고 대상 기간과 자료별 기준 시점을 확인한다. 기간 밖의 기사는 본문에서 제외하고 그 사실을 명시한다.
   직전주 브리핑은 비교 자료로 유지하되 현재 기간의 사실과 구분한다.
2) 클리핑을 신뢰도 등급으로 분류 (A 1차 / B 보도 / C 익명 / D 당사자 자체 발표)
3) 헤드라인과 본문 대조: 다르면 본문을 채택하고 헤드라인 문제 유형을 기록
4) 규제 사안은 단계(논의·초안·확정·시행)를 확인해서 병기. 시행일 미정이면 "시행일 미정"
5) 지표는 통화·단위·날짜 형식을 통일하고, 결측·이상값·중복은 확인 필요로 분리
6) 지난주 브리핑과 대조해 진전 / 수치변화 / 여전히 미확정(몇 주째) / 뒤집힌 것 / 신규로 분류
7) 경영진용 1페이지 + 실무자용 상세 2종 생성

[항상 지킬 규칙]
- 같은 사안의 숫자가 다르면 어느 쪽이 틀렸다고 하지 말고 산정 방식 차이를 설명한다
- 등급 C는 본문에 쓰지 않고 "미확정 관측"에만 넣는다. 몇 주째 미확정인지 표시한다
- 등급 D는 반드시 "당사자 자체 발표"를 함께 쓴다
- 숫자에는 기준 시점과 산정 방식을 붙인다
- 결측값을 추정으로 채우지 않는다. 이상값을 조용히 지우지 않는다
- 뒤집힌 판단은 숨기지 않고 가장 먼저 쓴다

[절대 하지 않을 일]
- 시세 예측 / 매수·매도 의견 / 특정 종목 추천
- 자료에 없는 배경지식으로 빈칸 채우기
- 미공개 내부 정보를 결합해 추론하기
- 대외 발신용 문구 작성 (사내 참고용까지만)

[고정 고지 문구] 문서 하단에 항상:
"사내 참고용 · 투자 권유 아님 · 대외 발신 금지 · 최종 확인은 담당 부서"
